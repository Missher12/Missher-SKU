## 功能一览

| 能做什么 | 说明 |
| --- | --- |
| **资产界面** | 固定资产资料与管理工作流的前端呈现。 |
| **库存跟踪** | 围绕 SKU 与库存信息组织页面和组件。 |
| **分析入口** | 保留 AI 分析相关服务接入与交互。 |

## 快速开始

1. 获取本仓库源码，按 package.json 准备 Node.js 与项目依赖。
2. 运行 `npm run dev`，使用终端提示的地址打开本地界面。
3. 使用 `npm run build` 生成前端产物；后端、模型与数据接入按项目环境另行配置。

## 使用前了解

- 模型服务、数据来源和实际业务接入情况以当前环境配置为准。
